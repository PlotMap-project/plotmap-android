# PlotMap Android

PlotMap is a pocket assistant for building and editing story lines.

The app helps writers structure a story as a graph:
- build a story graph from an existing draft with AI assistance
- create a story graph manually from scratch using the app tools

## How to run the project

### Requirements
- Android Studio
- JDK 17
- An Android device or emulator

### Run from Android Studio
1. Open the project in Android Studio.
2. Select a device or start an emulator.
3. Click **Run**.

### Run from the command line
From the project root:

```bash
./gradlew assembleDebug
```

To install the app on a connected device or emulator:

```bash
./gradlew installDebug
```
